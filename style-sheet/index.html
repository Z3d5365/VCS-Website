Two systems, one site worth knowing before you edit

The homepage carries its styles inline in index.html and uses a near-black accent. The subpages — /services/… and /search/ — share /assets/service.css, which defines its own tokens with a violet accent (#6d5efc, #8b7dff dark) and a violet→mint gradient. The two are deliberately close but not identical, so a token changed in one place does not follow into the other.

index.htmlHomepage tokens + all homepage components. Source of truth for this page — the block at the top of this file mirrors it.
assets/service.cssSubpage + search tokens and components. Violet accent variant.
portal/index.htmlClient portal, inline, its own smaller token set.
