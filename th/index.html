คำถาม

คำถามที่ทุกคนถาม

เว็บไซต์ใช้เวลานานแค่ไหน?

โดยทั่วไปประมาณสองสัปดาห์นับจากที่คุณส่งเนื้อหาและรูป เว็บหน้าเดียวง่าย ๆ อาจขึ้นได้ใน 3–4 วัน ถ้ามีเดดไลน์ที่แน่นอน บอกได้ในการคุยครั้งแรก แล้วผมจะบอกตรง ๆ ว่าเป็นไปได้ไหม

ค่าดูแลรายเดือนครอบคลุมอะไรบ้าง?

โฮสติ้ง, SSL, สำรองข้อมูลรายวัน, อัปเดตซอฟต์แวร์และความปลอดภัย, เฝ้าระวังการทำงาน และแก้ไขเนื้อหาเล็กน้อยได้สูงสุดหนึ่งชั่วโมงต่อเดือน — ราคาใหม่ รูปใหม่ เวลาเปิด-ปิด ยกเลิกเดือนไหนก็ได้ แล้วผมจะส่งไฟล์ให้

ผมต้องมีชื่อโดเมนของตัวเองไหม?

ใช่ และคุณควรเป็นเจ้าของเองแทนที่จะให้เอเจนซีถือไว้ ผมจะจดทะเบียนในชื่อคุณและคิดตามราคาจริง บัญชีเป็นของคุณ

ใครเป็นเจ้าของเว็บและเนื้อหา?

คุณเป็นเจ้าของทั้งหมด ทั้งโค้ด ดีไซน์ โลโก้ โดเมน และล็อกอิน ไม่มีค่าลิขสิทธิ์ให้ต่ออายุ ไม่มีการผูกมัด ถ้าคุณย้ายไปหานักพัฒนาคนอื่น ทุกอย่างโอนให้หมด

รับงานธุรกิจจากที่ไหนก็ได้ไหม?

ได้ — การสื่อสารส่วนใหญ่ทำผ่านอีเมล LINE หรือวิดีโอคอลอยู่แล้ว ผมทำงานตามเวลาอินโดจีน (UTC+7) และตอบภายในหนึ่งวัน ชำระเงินผ่านการโอนระหว่างประเทศหรือบัตร

เว็บจะเร็วไหม แล้ว Google จะชอบไหม?

ทุกเว็บสร้างด้วยมือและโหลดได้ในไม่ถึงสองวินาทีบน 4G ปกติ พร้อม Core Web Vitals สีเขียว ข้อมูลโครงสร้าง, sitemap, meta description และ Google Business Profile รวมอยู่ในราคาพื้นฐาน ไม่ใช่ของขายเพิ่ม
